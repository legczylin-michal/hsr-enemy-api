# Honkai: Star Rail

Honkai: Star Rail (HSR) is a game by HoYoverse.
Based on the [HSR wiki](https://honkai-star-rail.fandom.com/wiki/Honkai:_Star_Rail_Wiki) I created an application that does two thinks:
1. scraps data about enemies, thus creates HSR enemy API,
2. allows one to perform calculations specific to game mechanics (like calculating probability of inflicting negative effect on enemy considering different types of resistances).
